
# 🎀 Kitty Farm Simulator ♡

🌸 **Bem-vindo ao Kitty Farm Simulator!** 🌸

Um jogo de simulação e evolução inspirado nos jogos *Clicker* e *Pet Simulator*, onde você entra em um mundo mágico cheio de gatinhos fofos, moranguinhos e aventuras!

A ideia do projeto é criar uma experiência divertida e relaxante, na qual o jogador pode coletar recursos, chocar ovos mágicos, conseguir novos gatinhos e evoluir cada vez mais.

A cada conquista, sua fazendinha fica mais poderosa! 🍓

---

## 🐱 Sobre o jogo

No Kitty Farm Simulator, você começa com apenas um pouquinho de poder e precisa clicar no gatinho para ganhar moranguinhos 🍓.

Com os recursos acumulados, é possível comprar ovos mágicos, descobrir novos pets, adquirir melhorias e aumentar sua produção.

Quanto mais você evolui, mais longe consegue chegar!

## ✨ Funcionalidades

- 🍓 **Sistema de moedas:** ganhe moranguinhos clicando no gatinho.
- 🥚 **Ovos mágicos:** compre ovos e descubra novos companheiros.
- 🐾 **Sistema de pets:** colecione gatinhos com diferentes raridades e multiplicadores.
- 🎀 **Equipamentos:** equipe até 3 gatinhos para aumentar seus ganhos.
- 🛍️ **Loja de melhorias:** compre upgrades para aumentar seu poder.
- 🌸 **Sistema de níveis:** ganhe XP e suba de nível enquanto joga.
- 💎 **Rebirth:** reinicie parte do seu progresso para receber joias e multiplicadores permanentes.
- ⚡ **Farm automático:** seus gatinhos trabalham para gerar moranguinhos automaticamente.
- 💾 **Salvamento automático:** seu progresso fica salvo no navegador.

## 🐈 Raridades dos gatinhos

Existem diferentes tipos de gatinhos que podem ser encontrados nos ovos:

| Gatinho | Raridade | Multiplicador |
|---|---|---|
| 🐱 Gatinho Branco | Comum | x1 |
| 🎀 Gatinho Rosa | Comum | x1.5 |
| 🍓 Gato Morango | Raro | x3 |
| ☁️ Gato Nuvem | Épico | x7 |
| 🦄 Gato Unicórnio | Lendário | x20 |
| 🌟 Gato Estelar | Mítico | x75 |

Cada gatinho possui uma chance diferente de aparecer, tornando a coleção ainda mais divertida!

## 🥚 Tipos de ovos

O jogo possui quatro ovos mágicos:

- 🥚 **Ovo Rosa:** 100 moranguinhos.
- 🍓 **Ovo Morango:** 1.000 moranguinhos.
- 💗 **Ovo Mágico:** 10.000 moranguinhos.
- 🌈 **Ovo Celestial:** 100.000 moranguinhos.

Os ovos mais avançados permitem encontrar gatinhos de raridades superiores.

## 💎 Sistema de Rebirth

O Rebirth permite recomeçar parte da aventura em troca de recompensas especiais.

Ao realizar um renascimento:

- Suas moedas são zeradas.
- Seus upgrades são resetados.
- Seus níveis voltam ao início.
- Você recebe 10 joias mágicas.
- Seu multiplicador permanente aumenta.
- Seus gatinhos e sua coleção são mantidos!

## 🛠️ Tecnologias utilizadas

O projeto foi desenvolvido utilizando tecnologias web:

- **HTML5:** estrutura do jogo.
- **CSS3:** identidade visual, cores e estilização.
- **JavaScript:** mecânicas, cálculos, sistema de pets, upgrades e salvamento.

O progresso é armazenado localmente utilizando `localStorage` do navegador.

## 🚀 Como jogar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.
4. Clique no gatinho para começar a ganhar moranguinhos.
5. Compre ovos, descubra pets e evolua sua fazendinha!

## 🎀 Objetivo do projeto

O Kitty Farm Simulator é um projeto de desenvolvimento web criado com a ideia de unir programação, criatividade e diversão.

Além de desenvolver um jogo com uma identidade visual própria, o projeto também é uma forma de praticar JavaScript, manipulação do DOM, lógica de programação, gerenciamento de estado e armazenamento de dados no navegador.
